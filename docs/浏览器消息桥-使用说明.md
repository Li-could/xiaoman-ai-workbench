# 浏览器消息桥 · 本地登录店铺实时收客户消息

> 适用场景：**拿不到平台开放平台 API**（没有 AppKey / 权限审批不过 / 应用没上线），
> 但又需要在本机浏览器登录店铺后台后，实时接收客户发给店铺的消息。
>
> 对应代码：`extension/`（浏览器扩展）、`server.js` 的 `/api/bridge/*`、`/api/hooks/inbox/*`。

---

## 一、原理（为什么不用 API 也能收消息）

客户发的消息，店铺后台网页本来就展示在浏览器里（聊天列表、会话气泡）。
消息桥做的是「读屏」：

```
客户发消息 → 店铺后台网页聊天列表出现新内容
                │（扩展脚本 MutationObserver 监听 DOM 变化）
                ▼
        识别出「谁 + 说了什么」（指纹去重，同一句只报一次）
                │  POST 到本机
                ▼
   http://127.0.0.1:8787/api/hooks/inbox/<token>
                │
                ▼
   建/复用会话 → 触发工作流 → AI 首响 → 工作台实时出现
```

全程只在你本机浏览器与本机服务之间通信，**不上传任何数据到外部服务器**。

---

## 二、安装（一次性）

1. 在工作台「店铺管理 → 接入详情 → 消息接收」里点 **下载浏览器扩展**，得到 `xiaoman-bridge.zip`，解压。
2. Chrome / Edge 地址栏打开 `chrome://extensions`，右上角打开 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选解压后的文件夹。
4. 工具栏出现「小满消息桥」图标即安装成功。

## 三、使用

1. 用**本浏览器**登录店铺后台（拼多多 `mms.pinduoduo.com`、千牛 `qn.taobao.com`、抖店 `fxg.jinritemai.com` 等）。
2. 工作台「接入详情 → 消息接收」复制 **Webhook 地址**，粘贴进扩展弹窗并保存。
3. 回到店铺后台页面（聊天列表所在页）。扩展开始监听。
4. 客户发消息 → 工作台「会话聚合」顶部出现「收到 N 条新消息」，点开即见。

状态确认：工作台「接入详情 → 消息接收」顶部的 **网页监听** 指示灯，
绿色 = 正在监听，灰色 = 离线（检查扩展是否开启、工作台是否启动、Webhook 地址是否正确）。

## 四、抓不准时：自定义选择器

各平台后台的页面结构会调整。默认适配器抓不到消息时，在扩展弹窗「高级」里按 F12 找到聊天列表对应的 class 名，填自定义选择器：

- 会话列表容器：装所有会话的外层，如 `.conversation-list`
- 单个会话项：每个客户一条，如 `.session-item`
- 昵称：会话项里的昵称元素（留空自动取第一行）
- 最新消息：会话项里的最后一句（留空自动取最后一行）

保存后立即生效。

## 五、安全说明

- Webhook 令牌（`ik_...`）是店铺消息入口的唯一凭证，只发给可信的人。
- 令牌泄露时在「消息接收」里点 **重置**，旧地址立即失效。
- 扩展 `content_scripts` 只注入到平台后台域名，且只读取聊天列表文字。

## 六、与「开放平台 API」的关系

| | 浏览器消息桥 | 开放平台 API |
|---|---|---|
| 前提 | 本机登录店铺后台 | AppKey + 权限审批 + 应用上线 |
| 买家聊天消息 | ✅ 能收（读屏） | ❌ 平台不开放（除非服务市场签约） |
| 订单 / 退款事件 | ❌ 不收（只收聊天） | ✅ TMC 推送 |
| 需要本机一直开着浏览器 | 是 | 否（服务端轮询） |

两者可同时用：API 收订单/退款事件，消息桥收买家聊天，消息统一进工作台。

## 七、导入完整聊天记录（含图片、商品链接）

实时监听只能看到「会话列表预览」那一句话；要拿到和平台后台一模一样的完整对话
（买家账号、每一句文字、商品链接、买家发的图片、系统提示、每条消息的时间），
用「聊天记录查询」页导入：

1. 在拼多多商家后台打开 **多多客服 → 聊天记录查询**（能查出「消费者账号 / 聊天记录」两栏的页面）。
2. 选定时间范围，点「查询」，右侧出现该买家的完整聊天记录。
3. 点浏览器右上角「小满消息桥」→ 点 **导入本页聊天记录（含图片/链接）**。

扩展会逐个点开左侧每个买家账号，把右侧的整段对话读出来推到工作台：

- 买家账号（平台显示的脱敏名，如 `远***`）→ 工作台会话名
- 买家发的文字 / 商品链接（可点击打开）/ 图片（点击看大图）
- 我的回复（右侧蓝色气泡）
- 平台系统提示（如 `[常见问题列表]`）→ 居中灰色小条
- 每条消息的时间 → 用平台原始时间（`10-25 20:18`）

也可以不用点按钮：扩展弹窗里勾选 **停在「聊天记录查询」页时自动导入完整对话**，
停在该页面每 5 分钟自动采一轮。

注意：

- 采集过程会逐个点击左侧买家（约 1 秒/个），期间请不要切走标签页。
- 同一段记录重复导入不会重复，服务端按「角色 + 时间 + 内容」去重。
- 右侧记录分页时，先翻到对应页再点导入；多导几次即可补全。
- 会话列表预览仍然只显示「客户最近说的那句话」，预览不会被我们的回复覆盖。

对应接口（也可以由你自己的脚本调用）：

```
POST /api/hooks/inbox/<token>/thread
{
  "buyer": "远***",
  "channel": "web_拼多多",
  "messages": [
    { "role": "system",   "text": "[常见问题列表]", "time": "2026-10-25 20:18:57" },
    { "role": "customer", "kind": "link", "url": "https://mobile.yangkeduo.com/goods.html?goods_id=964811899", "time": "2026-10-25 20:19:01" },
    { "role": "agent",    "text": "在的哦", "time": "2026-10-25 20:19:25" },
    { "role": "customer", "kind": "image", "url": "https://img.pinduoduo.com/xxx.jpg", "time": "2026-10-25 20:20:03" }
  ]
}
```

图片走 `/api/img?u=` 代理（只放行拼多多/淘宝/京东/抖音等图片域名），避免 CDN 防盗链。

## 八、实时抓「当前正在聊的这个客户」的整段对话（v1.6.0 起）

以前实时监听只能拿到会话列表那一句预览。现在只要客户在聊天窗口里说话，
几秒内就能把**整段对话**同步到工作台：

1. 打开拼多多「多多客服」聊天页（保持标签页开着，可最小化）。
2. 点浏览器右上角「小满消息桥」：
   - 正常会显示 `识别到 N 条消息，当前客户：游客`；
   - 显示「当前页没被扩展接管」→ 按 F5 刷新这个页面（扩展更新后必须刷新）。
3. 点「抓取当前正在聊的这个客户」可手动立即同步一次。

判定规则（不依赖平台类名，改版也不容易坏）：

- 先找聊天输入框 → 从它向上找到可滚动的消息区；
- 每条消息看**头像在左还是在右**：左=客户，右=我方；
- 居中的短文本（如「以上是历史消息」）当系统提示；
- 消息里的图片（商品图/买家实拍）单独存一条，点击可看大图。

工作台里显示成：客户名 → 客户说的每句话 / 图片 / 商品链接 / 我方回复 / 系统提示，
列表预览始终是「客户最近说的那句话」。同一个客户重复同步不会产生重复消息
（按「角色+内容+时间」计数去重，客户连发两句「好的」也能正确区分）。
