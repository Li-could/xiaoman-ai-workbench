## 二、已完成的部署步骤

1. **Node 22.20.0**：二进制包安装到 `/usr/local/node`，软链到 `/usr/local/bin/{node,npm,npx}`
2. **代码上传**：`tar` 流式上传到 `/opt/xiaoman-workbench`（排除 node_modules/.git/data）
3. **依赖**：`npm install --omit=dev`（仅 mysql2，实际走 SQLite 未使用）
4. **环境变量** `/opt/xiaoman-workbench/.env`：
   - `DB_DRIVER=sqlite`、`DB_STRICT=0`
   - `PUBLIC_BASE_URL=https://kefu.zhimengxuan.com`（决定在线咨询链接与 Webhook 地址）
   - `TMC_POLL_MS=0`（未配置平台 API，关闭平台轮询节省资源）
5. **systemd** `/etc/systemd/system/xiaoman.service`：`Restart=always`，日志 `/var/log/xiaoman.log`
6. **nginx** `/etc/nginx/conf.d/kefu.zhimengxuan.com.conf`：
   - 80 → 301 跳 HTTPS（保留 `/.well-known/acme-challenge/` 供证书续期）
   - 443 反代，`proxy_buffering off`（AI 流式输出不被缓冲）
   - IP 直连 80 端口也可访问
7. **HTTPS 证书**：acme.sh + Let's Encrypt 签发 `kefu.zhimengxuan.com`，
   证书 `/etc/nginx/ssl/kefu.zhimengxuan.com/`，自动续期 cron 已存在（每天 4/10/16/22 点检查）
8. **数据迁移**：本地 MySQL 全量业务数据 3719 行导入线上 SQLite
   （租户 / 用户 / 店铺 / 会话 / 消息 / 素材 / 工作流 / AI 配置 / 店铺知识等）
